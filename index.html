📖 Правила игры в Бинго и требования к контенту

Добро пожаловать в конструктор образовательных игр Бинго! Ниже приведены правила для всех режимов и рекомендации по количеству элементов.

🎯 Цель игры:

Собрать непрерывную линию из фишек по вертикали, горизонтали или диагонали быстрее соперника!

🎲 Правило барабана:

Если из барабана выпадает картинка, которая есть на вашем поле в незакрытой клетке, кнопка «Достать карточку» блокируется! Вы обязаны кликнуть по клетке на поле, правильно ответить на задание и поставить фишку (или передать ход, если ошиблись), и только после этого сможете тянуть новую карточку.

🎲 Режимы игры:

  • Один игрок (1P): Ученик играет со своей карточкой. Нажимает кнопку барабана, ищет совпадение на поле, отвечает на учебное задание и стремится собрать Бинго (линию) за минимальное число ходов.
  • Два игрока / 2 команды (2P): Игроки ходят строго по очереди. При клике на правильную клетку открывается учебное задание. При верном ответе ставится фишка, при ошибке — фишка не ставится и ход переходит к сопернику.
  • Против компьютера (Comp): Вы играете Игроком 1 против ИИ (Игрок 2). После вашего хода компьютер автоматически делает свой ход, если находит совпадение.

📐 Поддержка математических формул (LaTeX):

Вы можете использовать математические формулы и дроби в вопросах и ответах! Оберните формулы в одиночные знаки доллара для встроенных формул ($x^2 + y^2 = z^2$) или в двойные знаки доллара для крупных выражений и дробей ($$\frac{a}{b}$$).

📦 Рекомендуемое количество контента:

  • Для сетки 3x3 (9 клеток):
    • Картинки для карточек: Минимум 9, оптимально 12–15 уникальных картинок/слов для разнообразия.
    • Учебные задания: Рекомендуется 15–30 вопросов в списке (если они закончатся, игра закольцует их сначала).
  • Для сетки 4x4 (16 клеток):
    • Картинки для карточек: Минимум 16, оптимально 20–25 уникальных картинок/слов.
    • Учебные задания: Рекомендуется 20–40 вопросов для полноценной игры.
